# TheTinkerCrow.com

The website for The Tinker Crow, a studio for handmade curiosities: glass,
metal, wood, leather, stone and thread, combined in ways they weren't meant
to go.

Plain static HTML/CSS served by GitHub Pages from `main`. Open `index.html`
through any local static server to preview (`python3 -m http.server`), since
the page uses root-relative paths.
